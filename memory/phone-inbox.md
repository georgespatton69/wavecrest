# Phone Inbox

Ideas and tasks captured on the go (phone/web Claude sessions). **Only phone/web sessions append here** — this avoids merge conflicts with laptop auto-writes to the other memory files.

**Workflow:**
- **On phone/web:** add a dated bullet under "Unprocessed" for any idea, note, or task. Commit + push.
- **On the computer:** `git pull`, then triage each item into the right file (e.g. [[client-colorado-behavioral]], [[wavecrest-dashboard]]), and delete it from here once filed.
